# Dojo evidence-budget v1 (2026-11-26)
Research: https://arxiv.org/abs/2609.08944 (SkillAdam, optimization memory and volatility-sensitive edit magnitude); https://github.com/gepa-ai/gepa (reflective candidate optimization); https://github.com/karpathy/autoresearch (fixed evaluation protocol).
The existing dojo already implements a hypothesis graph, comparative promotion, calibration and capability lanes. The missing part is allocating scarce user reviews to those lanes. This patch emits a shared, deterministic allocation and H-level failure memory via graph.stewardship.optimization; it does not train a model, reproduce SkillAdam, implement full GEPA, certify causes or release a skill.
After eight pinned exploration ratings, where fewer than eight capability ratings exist, reserve one free slot for approved-version fresh capability work, after the existing matched pair. Pending capability work prevents more reservations. Measurement-mode dojos keep operator-data evaluation. The thresholds are initial heuristics. Exclusive H, distinct material keys, recent human verdicts only; four to six repeated failures without positive matched evidence signal changing an operation rather than rewriting wording. Historical passes are retained as references. Counts are descriptive, material identities agent-declared, and pinned versions not independently verified production versions. All current submission, rating, preregistration and release gates remain. No new API expense or scheduled task.
Validation: add regression checks to the existing dojo graph suite. Real improvement requires new human-rated validation and capability results under fixed protocols, not passing software tests. Compare eight fresh capability cases with an earlier version under the same benchmark where available, and monitor actual paired completion. Roll back allocation guidance if it consumes review capacity without usable comparisons or degrades output quality.
