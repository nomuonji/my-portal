# Dojo evolution v2
Seven requested measures, grounded in existing graph/registry, no new schedulers or release gates.
- Prospective judging: queue exposes exact unrated text only, commit once per stable protocol (max 4 per trial), transaction rejects rated/backfilled/mutated samples, compare Brier on later genuine human ratings and same-case protocol pairs; exclude corrections/media. Separate reviewer must actually be available; no identity or independence attestation and not a hidden historical holdout. Do not fake one. No retrospective verdict guessing as evidence.
- Memory: mixed exclusive-H pass/fail references and prior positives; compare retrieval policy with a matched downstream test and use existing full casebook/texture review. No new automated memory learner.
- Regression: actual producing-version receipt groups plus separate pinned historical leads; use archived body and same fresh material through validation with receipt, no auto rollback.
- Five research components: analyzer, retriever, allocator, proposer, evolver. Use existing plannedFactors meta_hypothesis_id / meta_scope (prefix component:) / meta_arm for matched downstream attribution. Metrics remain descriptive, not approval. No five new registries or automatic skill evolution.
- Breakthrough: ten recent <=1 passes or repeated independent H failure, advisory alternatives: incremental, different operation, archived version. Preserve existing branch review and experiment budget. Synthesize complementary Hs through existing graph relations and rule proposals. No automatic candidate skill creation/crossover.
- Harness: diagnostic signals for low pass, false negative-rule clearance, absent capability measurement; isolate change in branch, fixed fixture and CI, explicit review. No automated code mutation or evaluator changes.

Read research notes in Agent Memory. Heuristics are reversible, unvalidated on new creative outcomes. Existing authority, gates, rating and release unchanged.
